# Public Release Checklist

Use this checklist before promoting Career Pipeline online or changing repository visibility/settings.

- [ ] Privacy scan completed against the full working tree and Git history.
- [ ] No secrets committed.
- [ ] No personal job-search data committed.
- [ ] No real company names, contact names, salaries, notes, emails, URLs, interview notes, exports, browser storage, or screenshots are committed.
- [ ] Screenshots sanitised and captured with fictional demo data only.
- [ ] Demo data verified as fictional only.
- [ ] `npm install` passes in a clean clone.
- [ ] `npm run dev` starts the app locally.
- [ ] `npm run build` passes.
- [ ] Mobile layout tested.
- [ ] Clean browser session tested with empty local data.
- [ ] README reviewed.
- [ ] Licence verified as Personal Use Only Licence.
- [ ] Source-available but not OSI open-source wording verified.
- [ ] Console logs removed.
- [ ] Debug code removed.
- [ ] Temporary developer comments reviewed or removed.
- [ ] Docker flow tested if Docker support is advertised.
- [ ] GitHub repository description and topics reviewed.
