# Public Release Checklist

Use this checklist before changing the GitHub repository visibility.

- [ ] Privacy review completed against the full working tree and Git history.
- [ ] No real company names, contact names, salaries, notes, emails, URLs, interviews, exports, browser storage, or screenshots are committed.
- [ ] Demo data verified as fictional only.
- [ ] Screenshots added using demo data only.
- [ ] README complete and accurate.
- [ ] `npm install` passes in a clean clone.
- [ ] `npm run dev` starts the app locally.
- [ ] `npm run build` passes.
- [ ] Licence verified as Personal Use Only Licence.
- [ ] No secrets or real `.env` files are committed.
- [ ] App tested on a mobile viewport.
- [ ] App tested in a clean browser session with empty local data.
- [ ] Docker flow tested if Docker support is advertised.
- [ ] Repository topics reviewed for accuracy.
- [ ] Repository visibility intentionally changed by the owner.
